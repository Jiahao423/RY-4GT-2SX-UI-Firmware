# RY-4GT-2SX 管理固件（UI 美化版）

> 本固件基于开源项目 **RTLPlayground**，为睿颖 RY-4GT-2SX 2.5G 傻瓜交换机定制编译。在保留原功能的基础上美化了 Web 界面，并修复了若干细节问题。
> 本仓库仅提供**固件二进制 + 源码改动**，不是完整的原项目。

## 支持设备

| 项目 | 说明 |
|---|---|
| 目标设备 | 睿颖 RY-4GT-2SX（PCB 丝印 `FG-4GT-2SX_V2.0`） |
| 主控芯片 | Realtek RTL8372N |
| 板载 Flash | P25Q32SH（4MB SPI NOR） |
| 端口 | 4 × 2.5G RJ45 + 2 × SFP+ |
| 平台 | SWTG024AS v2.0（编译目标 `SWGT024_V2_0_UNMANAGED`） |

同一平台可能由多个品牌贴牌，硬件相同即可适用；但刷机前请务必自行核对硬件与端口定义。

## 与原版的差异

- **Web 界面美化**：浅色仪表盘风格重新设计，概览/端口/VLAN 等页面布局更清晰。
- **端口名称在线编辑**：端口配置页 Name 列可直接输入并保存名称，无需命令行。
- **概览页字节计数修复**：原版把「包计数」当字节显示（大流量下载只有十几 MB），现改为正确统计入/出字节，速率与总量显示准确。
- **详细端口统计修复 + 中文翻译**：MIB 计数器名称中文化，统计页布局不再被挤掉。
- ⚠️ **去除登录页**：局域网免密码直接进入管理界面（删除 login.html，会话机制保留但不再触发）。**这是安全相关的修改，请仅在受信任的内网环境使用**，不要暴露到公网。

## 固件信息

| 项目 | 内容 |
|---|---|
| 固件文件 | `firmware/rtlplayground-v2fix6-20260808.bin`（512KB） |
| MD5 | `b43f119ba9de74db500d434fe811ac81` |
| 构建基线 | RTLPlayground commit `c86d4b3`（v0.1.0） |
| 内嵌默认 IP | `192.168.0.253`（网关 `192.168.0.1`，网段 `255.255.255.0`） |

刷入后交换机默认管理地址为 `http://192.168.0.253`，进 Web 后可在系统设置里改成你自己的网段（例如 `192.168.0.3`）。

## 已知问题

- **网口指示灯闪烁异常**：当前固件下网口指示灯会出现不正常的闪烁。这是已知的固件层面问题（推测是该板 LED 控制方式与原厂固件不同所致），不影响局域网数据转发。
